# Asset credits and licences

Everything in the shipped game is either made for this project or free for commercial use. **No attribution is legally required** for the CC0 packs; crediting them is a courtesy worth keeping in the game's credits.

## Third-party 3D models (106 used)

All were downloaded as GLB/glTF, then modified the same way by `art_src/blender/bake_kit.py`: colormap textures baked to per-face vertex colours, meshes joined, transforms applied, materials and UVs removed, re-exported as GLB. Nature kit and coaster foliage are also hue-shifted (`warm_foliage`). IDs in the game are `<pack>_<model>`, and the exact list is in `art_src/kit_used.json`.

## Tools

Blender 4.5 LTS builds the assets (GPL; the output is not GPL). It lives in the gitignored `tools/` folder and is not shipped.

## Original to this project

- 33 custom models: `assets/models/custom/*.glb`, generated by `art_src/blender/`.
- All music and ambience: `assets/audio/*.wav`, synthesised by `art_src/make_audio.py`. Nothing is sampled.
- All sound effects: synthesised at runtime in `src/audio/sfx.gd`.
- `assets/textures/paint_grain.png`: generated by `art_src/make_grain.py`.
